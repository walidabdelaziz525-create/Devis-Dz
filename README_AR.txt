Devis DZ V2 - دليل التشغيل
==========================
1) افتح index.html في Chrome على Android.
2) أنشئ عرضاً واملأ بيانات السباك والزبون والخدمات.
3) اضغط "حفظ العرض" لتخزينه محلياً.
4) افتح "سجل العروض المحفوظة" لاسترجاعه أو حذفه.
5) بيانات السباك الأساسية تحفظ لتسهيل العروض التالية.
6) إنشاء PDF يتم عبر طباعة المتصفح واختيار حفظ PDF.

النشر:
ارفع index.html إلى مستودع GitHub Public، ثم Settings > Pages > Deploy from a branch > main > /(root) > Save.

تنبيه:
البيانات محفوظة في localStorage داخل المتصفح نفسه. لن تنتقل تلقائياً إلى هاتف آخر، وقد تضيع عند مسح بيانات الموقع/المتصفح. صدّر أو اطبع العروض المهمة كـ PDF للاحتفاظ بنسخة.
الأداة تنشئ عروض أسعار تقديرية وليست فواتير ضريبية معتمدة.
