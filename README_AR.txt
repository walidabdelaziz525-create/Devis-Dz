Devis DZ PRO V3
================
برنامج تجريبي لإدارة أعمال السباكين المستقلين الذين يعملون مع فريق.

المحتويات:
- عروض أسعار قابلة للحفظ والتعديل والطباعة إلى PDF.
- إدارة الزبائن.
- تحويل عرض السعر إلى فاتورة.
- تسجيل الدفعات وحساب المبلغ المتبقي.
- تسجيل العمال وأدوارهم وأجورهم اليومية.
- تصدير نسخة احتياطية JSON واسترجاعها.
- العمل محلياً دون إنترنت بعد تحميل الصفحة.

طريقة التجربة:
1. افتح index.html في Chrome.
2. أنشئ عرض سعر واحفظه.
3. أضف زبوناً وعاملاً.
4. حوّل عرض السعر إلى فاتورة وسجل دفعة.
5. من قسم النسخ الاحتياطي نزّل ملف JSON ثم جرّب استرجاعه.

ملاحظات مهمة:
- V3 نسخة أولية تجريبية وليست نظاماً متعدد المستخدمين أو محاسبياً معتمداً.
- قائمة العمال إدارية على جهاز صاحب النشاط، ولا توجد حسابات دخول منفصلة للعمال.
- النسخ إلى Google Drive يتم يدوياً: نزّل ملف النسخة الاحتياطية ثم ارفعه إلى Drive.
- البيانات محفوظة في المتصفح على الجهاز. لا تمسح بيانات الموقع قبل تصدير نسخة احتياطية.
- لا توجد مزامنة تلقائية بين الأجهزة في هذه النسخة.
- يجب اختبار كل الوظائف على الهاتف قبل اعتمادها تجارياً.
